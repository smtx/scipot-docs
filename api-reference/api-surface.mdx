## Authentication & signup

Self-serve, no contracts. Email magic-link verification gives you an `ik_live_*` key and a default workspace.

| Method | Path | What it does |
|---|---|---|
| POST | `/auth/signup` | Register a new integrator. Sends verification email. |
| GET | `/auth/verify?token=…` | Exchange the email token for an API key (shown once). |
| POST | `/auth/resend-verification` | Resend verification email for a pending account. |

Full walkthrough: [Authentication →](/get-started/authentication).

## POTs (Knowledge Pots)

A POT is a knowledge container with a Constitution. Most workflows start with `POST /pots`.

| Method | Path | What it does |
|---|---|---|
| POST | `/pots` | Create a POT from JSON (canonical). |
| GET | `/pots` | List POTs in the workspace. |
| GET | `/pots/{pot_id}` | Get a POT by UUID. |
| GET | `/pots/by-slug/{slug}` | Get a POT by slug (workspace from `X-Workspace-ID`). |
| DELETE | `/pots/{pot_id}` | Soft-delete a POT. |

Concept: [Constitution →](/trust-mechanics/constitution).

## Facts

Atomic claims with POT Score + provenance. Most retrieval lands here.

| Method | Path | What it does |
|---|---|---|
| GET | `/pots/{pot_id}/facts` | List facts with filters (score, domain, tags, status, document, sort, paginate). |
| GET | `/pots/{pot_id}/facts/{fact_id}` | Get a single fact with full provenance. |
| GET | `/pots/{pot_id}/facts/{fact_id}/with-edges` | Get a fact plus its incoming/outgoing edges. |
| DELETE | `/pots/{pot_id}/facts/{fact_id}` | Delete a fact (cascades connected edges). |

Concept: [POT Score & Provenance →](/trust-mechanics/pot-score-and-provenance).

## Document ingestion

Two ingestion modes: inline text (JSON body) and file upload (multipart, with auto-conversion).

| Method | Path | What it does |
|---|---|---|
| POST | `/pots/{pot_id}/ingest` | Ingest raw text into a POT. Async, returns `job_id`. 100 KB inline cap. |
| POST | `/documents/upload` | Upload a file (PDF, DOCX, PPTX, XLSX, HTML, MD, TXT) — auto-converted to Markdown. Default 50 MB. |
| POST | `/pots/{pot_id}/extract-from-document` | Re-extract facts from a stored document into a (different) POT. |
| GET | `/documents` | List documents in the workspace (pagination via cursor). |
| GET | `/documents/{document_id}` | Document metadata + full content + extraction history. |
| PATCH | `/documents/{document_id}` | Update document metadata (tags, author, etc.). |
| DELETE | `/documents/{document_id}` | Delete document + its derived facts. |

Quickstart: [end-to-end ingest example →](/get-started/quickstart#step-3-ingest-a-document).

## Edges (typed relationships)

Five epistemic edge types + structural / causal / temporal / semantic categories. Drive POT Score propagation and contradiction detection.

| Method | Path | What it does |
|---|---|---|
| GET | `/pots/{pot_id}/edges` | List edges in a POT (filter by type, weight, fact). |
| POST | `/pots/{pot_id}/edges` | Create edges manually (triggers score propagation). |
| POST | `/pots/{pot_id}/edges/detect` | LLM-based edge detection vs the Constitution. |
| GET | `/pots/{pot_id}/edges/from/{from_id}` | Outgoing edges from a fact. |
| GET | `/pots/{pot_id}/edges/to/{to_id}` | Incoming edges to a fact. |
| DELETE | `/pots/{pot_id}/edges/{from_id}/{to_id}/{edge_id}` | Delete a specific edge. |
| POST | `/pots/{pot_id}/propagate` | Trigger POT Score propagation across the graph (run after bulk edge changes). |

Concept: [Contradiction Detection →](/trust-mechanics/contradiction-detection).

## Contradiction resolution

When two facts collide, the system flags. Humans resolve. The stances / resolve surface is **experimental** — shape may evolve.

| Method | Path | What it does |
|---|---|---|
| POST | `/pots/{pot_id}/edges/{edge_id}/stances` | Submit a stance on a CONTRADICTS edge (keep A, keep B, refine, defer). |
| GET | `/pots/{pot_id}/edges/{edge_id}/stances` | List stances on the edge. |
| POST | `/pots/{pot_id}/edges/{edge_id}/resolve` | Finalise the resolution (Curator action). |
| DELETE | `/pots/{pot_id}/edges/{edge_id}/resolve` | Revert a resolution (audit-trailed). |

Concept: [Contradiction Detection →](/trust-mechanics/contradiction-detection).

## Retrieval — Query, Search, CAG, Synthesis

Four retrieval surfaces composed by the Hybrid Router.

| Method | Path | What it does |
|---|---|---|
| POST | `/pots/{pot_id}/query` | Unified query — Hybrid Router picks CAG / RAG / GraphRAG / a combo. Returns ranked facts + routing metadata. |
| POST | `/pots/{pot_id}/synthesize` | Retrieve + LLM answer with epistemic briefing + cited facts + contradictions. |
| POST | `/pots/{pot_id}/search` | Direct RAG semantic search via embeddings. |
| POST | `/pots/{pot_id}/cag/search` | CAG keyword/entity search (&lt;5 ms). |
| POST | `/pots/{pot_id}/cag/warm` | Pre-load CAG cache for a POT. |
| GET | `/pots/{pot_id}/cag/stats` | CAG cache statistics. |

For most agent integrations, **`/synthesize` is the right endpoint** — it composes the full receipt-bearing response.

## Contribution & curation

Two roles: contributors (submit knowledge, expertise-weighted) and curators (approve, promote, govern).

| Method | Path | What it does |
|---|---|---|
| POST | `/pots/{pot_id}/facts/contribute` | Submit expert knowledge with declared expertise. Scored on contributor's domain authority. |

| GET | `/pots/{pot_id}/facts/{fact_id}/curations` | History of curation actions on a fact. |
| DELETE | `/pots/{pot_id}/facts/{fact_id}/curations/{curation_id}` | Revoke a curation (audit-preserved). |

Contributor registry (under workspaces):

| Method | Path | What it does |
|---|---|---|
| POST | `/integrator/workspaces/{ws}/contributors` | Register or update a contributor profile. |
| GET | `/integrator/workspaces/{ws}/contributors` | List contributors in a workspace. |
| GET | `/integrator/workspaces/{ws}/contributors/by-external/{external_id}` | Look up by your external user ID. |
| GET | `/integrator/workspaces/{ws}/contributors/{contributor_id}` | Get a contributor with expertise + history. |
| PATCH | `/integrator/workspaces/{ws}/contributors/{contributor_id}` | Update profile. |
| POST | `/integrator/workspaces/{ws}/contributors/{contributor_id}/roles` | Add a role (contributor, curator). |
| GET | `/integrator/workspaces/{ws}/contributors/{contributor_id}/roles` | Role history. |
| GET | `/pots/{pot_id}/contributors/{contributor_id}/actions` | What did this contributor do in this POT? |

## Billing (Stripe-managed)

Self-serve. No sales calls, no contracts.

| Method | Path | What it does |
|---|---|---|
| POST | `/integrator/billing/checkout` | Open a Stripe Checkout session — upgrade plan. |
| POST | `/integrator/billing/portal` | Open Stripe Customer Portal — manage cards, invoices, downgrade. |
| POST | `/integrator/billing/token-topup` | Buy additional token quota without a plan change. |
| POST | `/billing/webhook` | Stripe webhook receiver (Stripe → SciPot; you don't call this). |

Each call returns a Stripe-hosted URL. Redirect the user there; subscription state changes propagate via the webhook within seconds.

## Jobs

Async operations return a `job_id`. Poll the jobs API for status.

| Method | Path | What it does |
|---|---|---|
| GET | `/jobs/{job_id}` | Status + progress + result (or error envelope). |
| GET | `/jobs` | List recent jobs in the workspace. |

Webhook notifications for completed jobs are coming (milestone M22). Today, polling is the official path — 1–5 s interval is fine.
